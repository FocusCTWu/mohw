# 台灣藥酒癮醫療與復健資源地圖
Taiwan Addiction Treatment & Rehabilitation Service Map

互動式地圖：
https://openservice.tmapcenter.org/Taiwan_Addiction_service_map/Taiwan_Addiction_map_tool.html

## 專案目的

本工具將台灣藥癮、酒癮相關醫療與生活重建服務機構，
以互動式地圖方式呈現，協助使用者依「縣市」及「服務類型」
快速尋找可利用的服務資源。

本工具主要作為服務資源資訊整理與視覺化使用，
實際服務內容、資格及最新狀態仍應以各機構及主管機關公告為準。

## 主要功能

- 台灣各縣市服務機構地圖呈現
- 依縣市篩選機構
- 依服務項目進行複選篩選
- 顯示符合條件的機構數量
- 點擊地圖標記查看機構詳細資訊
- 支援機構 CSV 資料更新
- 支援縣市行政區界線 JSON 更新
- 當線上資料讀取失敗時，可由使用者手動上傳 CSV / JSON 作為備援

## 資料來源

### 機構資料
衛生福利部心理健康司  
「物質使用障礙症治療及生活重建業務指定機構名單」

資料會依主管機關(衛福部心健司)最新公開資料定期更新。

### 行政區界線
內政部國土測繪中心／政府開放資料之直轄市、縣市界線資料。

目前使用：
`COUNTY_MOI_1140318.json`

## 主要檔案

- `Taiwan_Addiction_map_tool.html`
  - 目前正式版互動式地圖

- `drug_org_list_all_*.csv`
  - 各期服務機構資料
  - 檔名中的數字為資料更新日期

- `COUNTY_MOI_1140318.json`
  - 台灣縣市行政區界線資料

- `Taiwan_Addiction_map_tool_*color_dev_safe20.html`
  - 歷史開發／測試版本

## 資料更新方式

衛福部心健司更新最新機構名單時：

1. 將新一期資料整理為既定 CSV 欄位格式。
2. 保留舊版 CSV，新增最新日期版本。
3. 修改 `Taiwan_Addiction_map_tool.html` 中預設載入的 CSV 檔名。
4. 更新網頁顯示的「資料更新時間」。
5. 測試：
   - CSV 是否正常載入
   - 縣市篩選是否正確
   - 各服務項目篩選是否正確
   - 地圖標記數量是否合理
   - 機構詳細資訊是否正常顯示
6. Commit 並部署更新。

## 使用方式

直接開啟線上版本即可使用。

建議操作流程：

1. 選擇縣市。
2. 勾選所需服務項目。
3. 地圖會顯示同時符合所有勾選條件的機構。
4. 點擊機構標記查看詳細資訊。

## 技術架構

本專案採純前端方式運作，主要由：

- HTML
- JavaScript
- CSS
- Web Map / Tile Layer
- CSV
- GeoJSON / JSON

組成。

不需要後端資料庫即可部署，
適合透過 GitHub Pages 或一般靜態網站伺服器提供服務。

## 注意事項

- 本地圖並非醫療轉介或預約系統。
- 機構服務內容可能隨時間變更。
- 如需正式轉介或確認服務資格，請直接聯繫服務機構。
- 若地圖資料與衛福部心健司最新公告不一致，以衛福部心健司公告為準。
